# Glow Studio — Demo Website

A responsive static demo website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive design and layout
- `script.js` — mobile navigation, footer year, and demo WhatsApp button

## Run locally
Open `index.html` in a browser, or open the folder in VS Code and use Live Server.

## Before using for a real business
- Replace demo wording, service details, and prices with approved information.
- Add the business owner's permissioned WhatsApp number in `script.js` to enable the contact button.
- Confirm you have permission to use any images and branding.
- This is a static front-end demo; it does not include a backend or booking system.

## Hosting
You can publish the static website with GitHub Pages from a public repository.
